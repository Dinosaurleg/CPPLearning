# Week 1 exercises

Keep your own exercise programs in this folder. Suggested names:

- `intro.cpp`
- `arithmetic.cpp`
- `temperature_converter.cpp`
- `number_guess.cpp`
- `calculator.cpp`

Compile one file at a time, for example:

```bash
g++ -std=c++20 -Wall -Wextra -Wpedantic -g projects/week-01/intro.cpp -o intro
./intro
```
